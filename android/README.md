# NoDopamine for Android 🍃

iOS 버전과 같은 기능을 가진 Android 앱이에요. (Kotlin + Jetpack Compose)

| 탭 | 할 수 있는 것 |
|---|---|
| **디톡스** | 15분~2시간 집중 세션 · 하루 목표 · 연속 달성일 🔥 · 최근 7일 그래프 · 오늘 참은 횟수 |
| **차단** | 차단할 앱 고르기 · 사이트 주소 입력 · **지금 바로 차단** · **매일 예약 차단** |
| **화면 단순화** | 흑백(회색조) 화면, 바로가기, 취침 모드 흑백, 홈 화면 비우기 등 체크리스트 |

## 폰에 설치하기 (Mac·개발자 계정 필요 없음)

### 방법 1. 만들어진 APK 받기 — 가장 쉬움
1. GitHub 저장소 → **Actions** 탭 → 왼쪽 **Android Build** → 맨 위(최신) 실행 기록을 눌러요.
2. 맨 아래 **Artifacts** 의 `NoDopamine-android-apk` 를 받아요. (GitHub 로그인 필요)
3. 압축을 풀면 `app-debug.apk` 가 나와요. 이 파일을 폰으로 옮겨요. (카톡 나에게 보내기, 구글 드라이브, USB 등)
4. 폰에서 APK 를 눌러 설치해요.
   - "출처를 알 수 없는 앱" 경고가 뜨면 → **설정** → 해당 앱(파일 관리자, 크롬 등)에서 **이 출처 허용** 을 켜요.
   - Play 프로텍트 경고가 뜨면 → **세부정보 더보기 → 무시하고 설치**.

### 방법 2. Android Studio 로 직접 빌드
1. [Android Studio](https://developer.android.com/studio) 설치 (Windows·Mac·Linux 모두 가능).
2. **Open** → 이 저장소의 `android` 폴더를 열어요. (처음엔 필요한 파일을 받느라 몇 분 걸려요)
3. 폰에서 **개발자 옵션 → USB 디버깅** 을 켜고 케이블로 연결해요.
   - 개발자 옵션 켜기: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드 번호** 7번 연속 터치
4. 위쪽에서 내 폰을 고르고 ▶︎ 를 눌러요.

## 처음 실행할 때: 접근성 권한 켜기 ⚠️

다른 앱이 열린 걸 알아채려면 **접근성** 권한이 필요해요. 앱 첫 화면의 안내를 따라 하면 돼요.

1. **접근성 설정 열기** → **설치된 앱** → **NoDopamine 앱 차단** → 켜기 → 허용
2. 회색으로 막혀서 안 켜지면 (**제한된 설정**):
   Play 스토어가 아닌 곳에서 설치한 앱은 안드로이드가 막아둬요.
   **앱 정보 열기** → 오른쪽 위 **⋮** → **제한된 설정 허용** → 다시 1번

> 이 권한으로 확인하는 건 **열린 앱의 이름**과 **브라우저 주소창**뿐이에요. 화면 내용을 저장하거나 밖으로 보내지 않아요.

## 테스트 체크리스트

| 확인할 것 | 방법 |
|---|---|
| 앱 차단 | 차단 탭 → 앱 고르기에서 유튜브 체크 → "지금 바로 차단" 켜기 → 유튜브 열기 → "잠깐, 쉬어가요" 화면 |
| 참은 횟수 | 차단 화면에서 "참았다! 닫기" → 디톡스 탭 숫자 +1 |
| 10초 대기 | "지금 바로 차단" 끄기 → 10초 뒤에야 "차단 풀기"가 눌려야 함 |
| 몰래 빼기 방지 | 차단 중에 앱 고르기 → 이미 고른 앱 체크박스가 회색이어야 함 |
| 사이트 차단 | 웹사이트에 youtube.com 추가 → 차단 켠 채 Chrome 에서 m.youtube.com 열기 |
| 집중 세션 | 15분 세션 시작 → 차단 앱 열어보기 → 15분 뒤 자동으로 풀리고 "완료" 기록 |
| 예약 차단 | 지금부터 몇 분 뒤 시작으로 설정 → 그 시각에 차단되는지 |

계산 로직(예약 시간, 주소 판별, 연속 달성일)은 **자동 단위 테스트**로도 확인해요.
`app/src/test/` 에 있고, GitHub 에 올릴 때마다 Actions 에서 자동으로 돌아가요.
Android Studio 에서는 테스트 파일을 열고 ▶︎ 를 누르면 돼요.

## 알아두면 좋은 한계

- **접근성 권한을 끄거나 앱을 지우면 차단이 풀려요.** 의지를 돕는 도구이지 완벽한 잠금 장치는 아니에요.
- **사이트 차단은 아래 브라우저에서만** 동작해요: Chrome, 삼성 인터넷, Firefox, Edge, Brave, 웨일.
  다른 브라우저를 쓰면 "차단할 앱"에서 브라우저 자체를 막으세요. 브라우저 업데이트로 주소창 구조가 바뀌면 안 될 수 있어요.
- **흑백 화면은 앱이 대신 켜줄 수 없어요.** (안드로이드 보안 정책) 화면 단순화 탭에서 방법을 안내해요.
- **Play 스토어에 올리려면** 접근성 권한을 쓰는 이유를 Google 에 따로 신고·심사받아야 해요. 내 폰에서 쓰는 건 상관없어요.

## 폴더 구조

```
android/
├── app/src/main/java/com/yehjunb/nodopamine/
│   ├── MainActivity.kt          ← 앱 시작점
│   ├── BlockerService.kt        ← ⭐ 차단의 핵심 (접근성 서비스)
│   ├── BlockActivity.kt         ← "잠깐, 쉬어가요" 차단 화면
│   ├── data/
│   │   ├── Models.kt            ← 예약 시간·연속 기록 계산 (테스트 있음)
│   │   ├── Domains.kt           ← 사이트 주소 판별 (테스트 있음)
│   │   ├── DetoxStore.kt        ← 데이터 저장소
│   │   ├── InstalledApps.kt     ← 설치된 앱 목록
│   │   └── Browsers.kt          ← 주소창을 읽을 브라우저 목록
│   └── ui/                      ← 화면들 (디톡스·차단·화면 단순화·앱 고르기·웹사이트)
├── app/src/test/                ← 자동 단위 테스트
└── app/src/main/AndroidManifest.xml
```
